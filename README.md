# IGNITE — Fire-Forged Gemstones Landing Page

A landing page reverse-engineered from the **Figma for Motion** template (*Ignite - Elemental Product*). Features a glowing 3D/cinematic fiery phoenix centerpiece with chapter-based scroll interactions, product modals, and atmospheric ambient flame audio.

## ✨ Features

- **60FPS Cinematic Centerpiece**: High-definition phoenix animation with interactive flame halo, wings, and ember dynamics.
- **Chapter-Based Navigation**:
  - `All Crystals`: Full Phoenix showcase.
  - `Rubies`: Floating golden feather transition.
  - `Crowns & Rings`: High-jewelry molten ring reveal.
- **Interactive Modals**: Detailed product inspection and pre-order reservation for *Flame Blaze* and *Ember Crown*.
- **Atmospheric Audio Engine**: Procedural primordial flame ambiance synthesized via the Web Audio API.
- **Clean Vanilla Architecture**: Pure HTML5, CSS3, and JavaScript powered by GSAP.

## 🚀 Getting Started

Clone the repository and serve with any local static server:

```bash
# Clone the repository
git clone https://github.com/mihir0246/ignite-elemental-product.git

# Navigate into the folder
cd ignite-elemental-product

# Start a local server (e.g. using Python)
python -m http.server 5173
```

Then open `http://localhost:5173` in your browser.
